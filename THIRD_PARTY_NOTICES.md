## Optional NVIDIA DLSS support

The default Windows build ships without the NVIDIA SDK and its runtime files. An experimental build with DLSS enabled links the SDK library. NVIDIA components remain subject to the [NVIDIA RTX SDKs License](https://github.com/NVIDIA/DLSS/blob/main/LICENSE.txt). The [official SDK source and downloads](https://github.com/NVIDIA/DLSS) are available from NVIDIA.
